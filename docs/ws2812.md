# WS2812 RGB 灯带

无需修改源码即可试用：见 [组件调试应用](component_demo.md)，通过 menuconfig 配置接线，再使用网页控制和查看状态。

可选模块名 `ws2812`，接口见 [ws2812.h](../components/ws2812/include/ws2812.h)。每个实例通过 RMT 驱动一条 RGB WS2812 灯带，使用固定版本 `espressif/led_strip` 3.1.0，支持常亮、呼吸、流水和闪烁。

```bash
bash tools/idf.sh --app satellite --modules ws2812 build
bash tools/idf.sh --app satellite --modules mpu6050,ws2812 build
```

应用组件在 `idf_component_register` 后使用 `idf_component_optional_requires(PRIVATE ws2812)`，源码通过 `CONFIG_MCU_ENABLE_WS2812` 判断是否选择。默认应用组合不会自动增加灯带或占用数据 GPIO。

## 接线与创建

`gpio` 连接灯带 DIN；电源按实际灯珠规格配置，并与开发板共地，GPIO 只传输数据，不给灯带供电。是否需要数据电平转换取决于灯珠电压和输入门限。灯珠数由应用明确配置，范围 1～512。

```c
#include "ws2812.h"

// APP_LED_DATA_GPIO 是应用按实际接线定义的 GPIO 编号。
ws2812_config_t config = WS2812_CONFIG_DEFAULT(APP_LED_DATA_GPIO, 16);
ws2812_handle_t leds;
ESP_ERROR_CHECK(ws2812_create(&config, &leds));

// RGB 红色，亮度 64/255，整条常亮。
ESP_ERROR_CHECK(ws2812_set_color(leds, (ws2812_color_t){255, 0, 0}, 64));

// 蓝色呼吸，一个完整周期 2 秒。
ws2812_effect_config_t effect = {
    .effect = WS2812_EFFECT_BREATH,
    .color = {0, 64, 255}, .brightness = 80,
    .period_ms = 2000,
};
ESP_ERROR_CHECK(ws2812_set_effect(leds, &effect));

// 流水灯：整条走一遍 1 秒，带 4 颗渐暗拖尾，可反向。
effect.effect = WS2812_EFFECT_CHASE;
effect.period_ms = 1000;
effect.tail_length = 4;
effect.reverse = true;
ESP_ERROR_CHECK(ws2812_set_effect(leds, &effect));

// 闪烁：一个亮/灭周期 0.5 秒。
effect.effect = WS2812_EFFECT_BLINK;
effect.period_ms = 500;
ESP_ERROR_CHECK(ws2812_set_effect(leds, &effect));

ESP_ERROR_CHECK(ws2812_stop(leds));
ESP_ERROR_CHECK(ws2812_destroy(leds));
```

示例展示接口顺序，连续立即调用会直接切换效果；实际应用应由业务事件调用、保留所选效果运行，而不是把示例当作延时演示。创建时灯珠全灭，默认配置使用 GRB 物理字节顺序、DMA、20 ms 刷新间隔；API 颜色始终按 RGB 传入。若实物颜色顺序不同，可将 `color_order` 设为 `WS2812_ORDER_RGB`。不支持 RGBW 灯珠。

RMT 通道由底层驱动自动分配，GPIO 由共享资源组件互斥登记；资源不足时创建失败。RMT 不使用舵机或风扇的 LEDC 通道/定时器。ESP32-S3 默认配置启用 DMA，可减少 Wi-Fi 活动造成的中断处理压力，最终效果仍需实物确认。

## 效果参数与生命周期

| 效果 | 行为 |
| --- | --- |
| `WS2812_EFFECT_OFF` | 停止动画，全灭 |
| `WS2812_EFFECT_SOLID` | 整条常亮 |
| `WS2812_EFFECT_BREATH` | 全灯同步渐亮渐暗，使用平方亮度曲线 |
| `WS2812_EFFECT_CHASE` | 光点循环移动，可配置渐暗拖尾与反向 |
| `WS2812_EFFECT_BLINK` | 每周期前半段亮、后半段灭 |

所有效果都接受 RGB 颜色与 0～255 亮度。动画周期范围 100～60000 ms，呼吸/闪烁表示一个完整周期，流水表示整条走一遍。`tail_length=0` 表示单颗流水光点，其余值不能超过灯珠数；`reverse` 只影响流水方向。单颗灯珠可呼吸/闪烁，但无法呈现空间流水。

每个实例创建一个独立动画任务（3072 字节栈、优先级 4），不在共享定时器回调里阻塞发送。常亮/关闭时任务等待通知，动画时按配置的刷新间隔生成帧；`refresh_interval_ms=0` 默认 20 ms，其余范围 10～1000 ms。灯珠较多或刷新较慢时会跳过中间动画相位，以实际经过时间计算当前效果，不承诺固定帧率。

`set_effect` / `set_color` 同步发送第一帧，后续由后台任务继续；调用者无需反复延时刷新。每次只串行发送一帧，发送本身仍会耗时，不能从 ISR 调用。改变效果会重新计时，`stop` 停止动画并熄灯。`get_status` 返回当前请求的效果、最近一次发送错误及成功帧数；设置或后台刷新失败时应检查错误，不能仅凭配置值认定灯珠已经显示成功。

`destroy` 等待后台任务退出，再熄灯并释放 RMT/GPIO；销毁期间应用必须排除其他使用者。若熄灯或资源释放失败，返回错误并保留句柄，可重试销毁；此时不再接受新的灯效命令。

## 验证与资料

本机测试编译实际效果代码与后台任务，替代底层 RMT 驱动，验证颜色/亮度、呼吸边界、流水拖尾/反向、闪烁、后台刷新、停止与任务退出、创建失败回收、错误状态、销毁重试及 GPIO 冲突。已验证单独和与 MPU6050、摄像头等模块组合构建；实际时序、颜色顺序、供电与最大可用灯珠数需按灯带上板验证。

底层接口见 Espressif 的 [LED Strip 文档](https://espressif.github.io/idf-extra-components/latest/led_strip/api.html)，依赖版本见 [led_strip 3.1.0](https://components.espressif.com/components/espressif/led_strip/versions/3.1.0)。
